# ADR-0003：AI 原生双循环与人工交易边界

状态：已接受；真实账户与委托边界已部分替代
日期：2026-07-28

> 2026-08-06 更新：本文关于永久排除真实账户和实盘适配器的结论，已由
> `docs/superpowers/specs/2026-08-06-ai-quant-portfolio-platform-design.md` 替代。
> Paper/Mirror 仍为默认模式；未来实盘必须显式授权、隔离运行并经过确定性硬风控。
> LLM 和外部 Agent 不得直接发送委托的边界保持有效。

## 决策

AstraQuant 定位为 AI 主导的量化研究与交易平台，采用离线研究训练与在线实时推理双循环。

AI 通过版本化 `FeatureFrame`、`ModelArtifact` 和 `SignalFrame` 参与研究与实时决策。平台提供买卖点、仓位、止损、止盈、置信度、理由和风险提示，并使用确定性回测与 Paper 模拟评估信号。

AstraQuant 永久不连接真实交易 Gateway，不保存券商或 CTP 交易凭据，也不发送真实委托。用户在外部券商或期货软件中手动操作，可选择回到 AstraQuant 记录实际成交用于复盘。

历史与实时数据共享标的、`Tick`、`Bar`、事件时间和可用时间语义，但批处理与流式传输实现相互独立。大语言模型不进入低延迟订单热路径。

## 原因

- AI 是产品核心而非后期外挂，数据层必须从 Phase 2 起支持特征时态、模型版本和防未来数据泄漏。
- 离线训练和在线推理解耦，可以同时支持日线、分钟和 Tick 策略。
- 结构化信号边界让模型可以替换、比较、回放和审计。
- 人工外部交易边界从结构上避免模型或软件缺陷直接操作真实账户。
- 本地优先的模型与数据边界保护策略、行情、账户和训练产物。

## 结果

- Phase 2 的数据契约必须包含 `event_time`、`available_time` 和版本化特征快照。
- Phase 3 必须建立模型注册、评估门槛和可重复 AI 回测。
- Phase 4 必须验证离线/在线特征等价后才能进行实时提示与 Paper 推理。
- Phase 5 只实现通知、可复制建议、人工确认、实际成交记录和复盘，不实现实盘适配。
- 任意试图保存券商/CTP 交易凭据或发送真实委托的代码都违反产品架构。
- 每条买卖提示必须可追溯到数据、特征、模型、信号与风险说明。
