# 许可证与采用矩阵

本文是工程决策记录，不构成法律意见。正式对外发布可执行版本前，应再次核对依赖的实际版本、许可证文本和 NOTICE 要求。

## 采用等级

| 等级 | 含义 |
| --- | --- |
| A：直接依赖 | 通过官方包管理器使用，锁定版本并记录许可证 |
| B：适配集成 | 外部项目保持独立，通过 AstraQuant 接口调用 |
| C：架构借鉴 | 学习概念和边界，使用自主命名与自主实现 |
| D：禁止复制 | 不复制源码、素材或受限制实现 |

## 仓库要求

后续引入第三方依赖时必须同步完成：

1. 在锁文件中固定直接依赖版本。
2. 更新 `THIRD_PARTY_NOTICES.md`。
3. 记录用途、许可证、项目主页和归属要求。
4. 检查依赖是否会改变 AstraQuant 的分发义务。
5. 禁止提交来源不明的动漫图片、字体、图标、数据集或模型权重。
6. 原创主题素材应保留生成记录或作者授权记录。

## 数据许可证

代码开源不代表行情和财务数据可以再分发。AstraQuant 默认只提供数据适配器和用户本地导入能力，不将第三方行情数据提交到 GitHub，也不在安装包中捆绑未获授权的数据。
