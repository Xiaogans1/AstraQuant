# 行情指标与量化状态前端收尾设计

日期：2026-08-06  
状态：已获用户确认

## 1. 目标

在进入真正的量化模型开发前，将行情图前端收敛为稳定、清晰且符合国内券商使用习惯的版本：

- 分时图显示价格线、累计均价线和成交量；
- K 线主图正确显示 MA 或 BOLL；
- VOL、MACD、KDJ、RSI 作为副图指标显示；
- 主图指标、副图指标和量化信号图层互不干扰；
- 量化状态能够诚实区分加载、接口失败、预热、抑制、观察和买卖提示。

本次不增加新的量化模型、不生成历史买卖点、不接入真实交易账户。

## 2. 已确认的根因

现有实现把所有指标放在同一个菜单中，并使用
`chart.createIndicator(indicator, isStack)`，但没有为 MA/BOLL 指定 K 线主窗格
`candle_pane`。因此主图指标被当成独立窗格创建，选中状态与实际图层不一致。

分时模式还通过 `period !== "intraday"` 跳过了所有技术指标，因此不会出现国内行情软件常见的累计均价线。

量化接口返回 `undefined` 时，界面把加载结束、请求失败和不可用统一显示为“等待行情”，用户无法判断真实原因。当前接口只返回最新决策，不能形成当天历史 B/S 序列。

## 3. 指标信息架构

工具栏拆分为两个独立选择器：

```text
[分时] [日K] [周K] [月K] [年K]   [周期]
主图：均价 / MA / BOLL / 无        副图：VOL / MACD / KDJ / RSI
```

### 3.1 分时

- 默认主图为 `AVG` 累计成交均价线，价格线保持现有青色，均价线使用克制的琥珀色；
- 均价按累计成交额 / 累计成交量计算；成交额不可用时使用分钟典型价按成交量加权，
  不使用未来数据；
- 主图顶部显示 `均价` 与当前价格；
- 副图默认 `VOL`，允许切换到 MACD、KDJ 或 RSI；
- 分时不显示蜡烛 MA/BOLL，避免把日 K 语义错误套用到分时价格线上。

### 3.2 K 线

- 主图默认 `MA`，参数为 5、10、20、60；
- `BOLL` 使用 20 日和 2 倍标准差，三条线叠加到 `candle_pane`；
- 选择“无”时移除主图技术指标，但保留蜡烛、十字光标和量化图层；
- 副图默认 `VOL`，MACD、KDJ、RSI 在同一个副图窗格内互斥切换，避免画布被无限压缩；
- 主图顶部显示当前光标数据点对应的 MA 或 BOLL 数值。

### 3.3 图层隔离

- 主图指标使用固定 `paneId: "candle_pane"`；
- 副图使用固定 `paneId: "astraquant_secondary_pane"`；
- 量化覆盖物继续使用独立 `groupId: "astraquant-quant-signals"`；
- 切换指标只移除对应 pane 的指标，不调用无过滤条件的 `removeIndicator()`；
- 切换周期、实时刷新和图表重排不得删除量化覆盖物。

## 4. 量化状态展示收尾

本次保留 `baseline-v1`，只改善状态可见性：

- `LOADING`：正在计算实时特征；
- `ERROR`：量化接口失败，显示可操作的简短原因；
- `WARMING_UP`：显示完成分钟数，例如 `12/20`；
- `SUPPRESSED`：显示行情非实时、数据过期等原因；
- `ACTIVE/HOLD`：显示继续观察和策略版本；
- `ACTIVE/BUY`、`ACTIVE/SELL`：显示置信度，并在图中创建 B/S 标记。

量化图层增加“显示/隐藏”控制，但默认显示。用户隐藏图层只影响展示，不停止后端计算。

当前接口只返回最新一次决策，所以本阶段不伪造历史 B/S 点。当天历史决策持久化与回放属于下一阶段量化闭环。

## 5. 组件边界

- `MarketChartToolbar`：周期、主图指标、副图指标、量化图层和全屏控制；
- `ProfessionalMarketChart`：固定窗格管理、KLineCharts 指标创建与量化覆盖物；
- `intradayAverage`：分时累计均价的纯函数和自定义指标定义；
- `MarketWorkspace`：状态选择、查询错误映射和用户可见说明；
- KLineCharts 只负责绘制，前端不自行生成交易信号。

## 6. 错误与降级

- 指标创建失败：保留行情本体，在状态区域提示“指标暂不可用”；
- 分时成交量或成交额不足：均价线从可计算的第一个点开始，不伪造零值；
- 量化 API 失败：行情图继续工作，量化条显示错误而不是“等待行情”；
- 数据不足：显示预热进度，不创建 B/S 标记；
- 无 BUY/SELL：明确显示 HOLD，不用装饰性标记制造活跃感。

## 7. 验收标准

1. 日 K 选择 BOLL 后，UP/MID/DN 三条线叠加在蜡烛主图。
2. 日 K 选择 MA 后显示 MA5/MA10/MA20/MA60，选择“无”后完全移除。
3. 分时默认显示累计均价线，且不会显示错误的蜡烛 MA/BOLL。
4. VOL、MACD、KDJ、RSI 在固定副图中互斥切换。
5. 切换主图或副图指标不会删除 B/S 覆盖物。
6. 指标菜单文字与真实图层始终一致。
7. 量化请求失败、预热、抑制、HOLD、BUY、SELL 均有不同的用户可见状态。
8. 当前只有最新决策时不伪造历史买卖点。
9. 全屏、缩放、光标联动和实时刷新回归测试继续通过。
