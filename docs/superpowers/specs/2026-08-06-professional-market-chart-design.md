# AstraQuant 专业行情主图设计

**状态：** 已确认  
**日期：** 2026-08-06  
**范围：** 中国 A 股、ETF 与国内期货的真实行情主图、周期数据与未来量化信号图层

## 背景与问题

当前首页右侧图表是为验证真实分钟数据而写的 SVG 预览。它存在四个产品级缺陷：

1. 东财 `current()` 对已验证的股票、ETF 和指数快照不返回 `pre_close`，现有映射将缺失昨收错误地解释为 `0`，最终显示 `+0.00%`。
2. 分时横轴按已有样本等距铺满容器，10:02 的最新样本会错误落在全天最右端，而不是停在 10:02 并为后续交易时间留白。
3. 图表只有约 150px 高，无法承载成交量、十字光标、技术指标以及后续量化买卖点。
4. 只有当日 60 秒数据，没有券商软件常见的分钟 K、日 K、周 K、月 K 和年 K。

真实 SDK 探针确认：

- `current()` 返回实时价格、今开、最高、最低、成交量和成交额，但没有昨收；
- `history_n(..., frequency="1d", count=1)` 返回上一交易日完整日 K，可作为当日昨收；
- `60s`、`300s`、`900s`、`1800s`、`3600s` 和 `1d` 均可读取真实数据；
- SDK 不提供稳定的周、月、年频率，必须从真实日 K 在本地确定性聚合。

## 产品目标

把行情预览升级为首页中的专业行情工作区。用户选择自选标的后，应能：

- 立即看到真实当前价、涨跌额、涨跌幅和行情时间；
- 查看今开、最高、最低、昨收、成交量和成交额；
- 在分时、分钟 K、日 K、周 K、月 K、年 K 之间切换；
- 通过十字光标读取任意一根行情记录；
- 查看成交量和基础技术指标；
- 在同一时间轴上承载未来量化买点、卖点、止损线、目标区间和 AI 策略修订；
- 清楚地区分真实行情、延迟快照、休市数据和不可用状态。

软件继续保持只读，不展示未经数据源支持的 Level-2 五档盘口和逐笔成交，不生成演示买卖点。

## 开源底座选择

采用 `klinecharts` 10.x 核心库，不采用完整的 KLineChart Pro 外壳。

理由：

- Apache-2.0 许可证；
- 面向金融行情而不是通用图表；
- 内置 K 线、面积线、成交量、多面板、十字光标和常用指标；
- 支持自定义 Overlay，未来信号不需要修改行情数据；
- Canvas 性能适合 Tauri WebView2；
- 允许 AstraQuant 保留自己的简约主题、深色主题和动漫背景层。

不选择其他方案的原因：

- TradingView Lightweight Charts 性能和成熟度很好，但技术指标、绘图工具和中国市场分时需要更多自研；
- Apache ECharts 更适合通用可视化，金融交互和长期扩展不如专用图库；
- KLineChart Pro 的现成 UI 不适合 AstraQuant 的信息架构和主题系统。

依赖固定到已验证的 `klinecharts@10.0.2`，升级必须经过视觉与数据回归测试。

## 信息架构

首页从“自选和小图并排”改为纵向行情工作区：

```text
┌ 核心指数带 ─────────────────────────────────────────────┐
├ 自选列表、搜索与连接状态 ─────────────────────────────────┤
├ 标的名称、代码、更新时间                                  ┤
│ 当前价 / 涨跌额 / 涨跌幅                                  │
│ 今开 / 最高 / 最低 / 昨收 / 成交量 / 成交额                │
├ [分时] [日K] [周K] [月K] [年K]  [周期⌄] [指标⌄] [全屏] ┤
├ 专业价格主图（全宽，最小 430px）                            ┤
├ 成交量或技术指标副图                                       ┤
└ 后续 AI 情报、量化策略、Paper 模拟区域                      ┘
```

桌面宽屏下自选表保持完整宽度，主图位于其下方并使用页面主宽度。窄屏按相同顺序单列。主图正常模式高度为 520px，低高度窗口不低于 430px；全屏模式占据除应用导航外的可用高度。

## 周期与指标交互

周期采用两级层次，避免把所有分钟周期横向堆在页面顶部：

- 一级常用周期：`分时`、`日K`、`周K`、`月K`、`年K`；
- 二级“周期”菜单：`1分`、`5分`、`15分`、`30分`、`60分`；
- 选择分钟周期后按钮显示当前状态，例如 `周期：5分`；
- “指标”菜单提供 `MA`、`BOLL`、`MACD`、`KDJ`、`RSI`；
- 默认 K 线叠加 `MA5/10/20/60`，副图默认 `VOL`；
- 分时默认显示收盘价面积线、昨收基准线和成交量；均价线仅在真实成交额和成交量可计算时显示。

键盘焦点、按钮选中态和菜单均具备可访问名称。所有周期和指标切换必须保留当前标的，不闪回旧标的数据。

## 真实数据契约

### 行情快照

`LiveQuote.previous_close` 改为可空。缺少昨收时，涨跌额和涨跌幅也必须为空，禁止返回零。东财 Provider 为每个活跃标的按交易日缓存上一交易日收盘：

1. 首次遇到标的或交易日变化时读取一根已完成日 K；
2. 将其 `close` 作为当日 `previous_close`；
3. 缓存在内存中，不进入 Git，不保存 Token 或原始行情转储；
4. 获取失败时保持涨跌值为空，页面显示 `—`。

参考价查询不得拖慢三秒实时轮询：每轮只补充有限数量的缺失参考价，已缓存标的不重复请求。

### 多周期 Bar API

新增：

```text
GET /v1/market/instruments/{instrument_id}/bars?period={period}&count={count}
```

合法周期：

```text
intraday, 1m, 5m, 15m, 30m, 60m, 1d, 1w, 1mo, 1y
```

映射：

| AstraQuant | 东财 |
| --- | --- |
| `intraday`, `1m` | `60s` |
| `5m` | `300s` |
| `15m` | `900s` |
| `30m` | `1800s` |
| `60m` | `3600s` |
| `1d` | `1d` |
| `1w`, `1mo`, `1y` | 从真实 `1d` 本地聚合 |

公开 Bar 采用严格结构：

```text
timestamp, open, high, low, close, volume, turnover, previous_close
```

数值使用 JSON number，时间使用带时区 ISO-8601；进入 KLineChart 前统一转换为毫秒时间戳并排序、去重。周、月、年聚合遵循：

- 开盘：周期第一根；
- 最高：周期最大值；
- 最低：周期最小值；
- 收盘：周期最后一根；
- 成交量和成交额：求和；
- 未结束的当前周期允许展示，但标记为实时形成中。

原 `/intraday` 接口在过渡期保留，由新服务实现转发，避免已有调用立即失效。

## 分时时间轴

中国 A 股、ETF 和指数使用固定交易坐标：

```text
09:30 ───── 11:30  空档  13:00 ───── 15:00
```

最新数据只绘制到其真实分钟位置，未来分钟保持空白。午休不能压缩成一条连续交易线，也不能把 11:30 和 13:00 合并成一个伪时间点。

具体月份期货合约继续使用实际 Bar 时间，不套用 A 股交易模板；期货夜盘时段将在独立的交易时段配置中实现。首轮若无法可靠识别期货完整时段，使用 K 线时间轴并明确标记，不伪造固定时段。

## 图表组件边界

前端拆分为：

- `MarketWorkspace`：标的摘要、周期状态和工作区布局；
- `MarketChartToolbar`：一级周期、分钟菜单、指标菜单和全屏；
- `ProfessionalMarketChart`：KLineChart 生命周期、主题、ResizeObserver 和数据加载；
- `marketChartData`：严格的 Bar 解析、排序、去重和周期展示规则；
- `marketChartTheme`：由 AstraQuant CSS 令牌生成 KLineChart 样式；
- `marketSignalOverlay`：未来确定性信号的独立适配层。

React 组件卸载、切换标的或周期时必须释放旧图实例和订阅，避免旧数据闪现与内存泄漏。

## 信号图层

首轮只定义并测试接口，不生成交易建议：

```ts
type MarketSignalMarker = {
  id: string;
  timestamp: number;
  side: "BUY" | "SELL";
  price: number;
  label: string;
  source: "QUANT";
};
```

未来信号进入 KLineChart Overlay：

- 买入观察点：`B`，位于 Bar 下方；
- 卖出观察点：`S`，位于 Bar 上方；
- 止损和目标：带标签的水平线；
- AI 只解释结构化信号，不可伪装成量化核心信号。

标记必须可隐藏，并且不参与价格计算和原始 Bar 持久化。

## 视觉系统

本轮延续 AstraQuant 的冷静浅色终端主题：

- 背景 `#eef5f4`，图表面板 `#f8fbfa`；
- 上涨 `#ef4b55`，下跌 `#16a56a`，平盘 `#718287`；
- 价格线使用青蓝，均价线使用克制的金色；
- 数值使用现有等宽数据字体，中文使用清晰的 UI 字体；
- 网格线低对比，不使用发光、玻璃拟态或无意义动画；
- 动漫背景只能出现在工作区外围，图表画布保持足够对比度。

独特元素仍为“星轨信号线”：量化信号、止损和 AI 策略修订共享一条可审计时间轴，但不暴露模型思维链。

## 错误与状态

- 未选择标的：引导用户从自选选择；
- 加载中：图表骨架，不显示旧标的数据；
- 暂无 Bar：说明所选周期暂无真实数据；
- 数据延迟：保留最后真实 Bar 并显示延迟标签；
- 休市：展示真实历史和最后更新时间；
- Provider 错误：图表保留最后可信数据，提供重连入口；
- 昨收缺失：涨跌额和涨跌幅显示 `—`，不显示 `0.00%`；
- 无成交额：不显示均价线，不计算错误 AVP。

## 测试与验收

### 自动测试

- 当前快照缺失昨收时涨跌值为空；
- 参考日 K 成功后产生正确涨跌额和涨跌幅；
- 参考价按标的和交易日缓存；
- 六个东财原生周期映射正确；
- 周、月、年 OHLCV 聚合正确；
- API 拒绝未知周期和过大 count；
- 图表输入完成时间转换、排序、去重；
- 周期栏采用一级周期和分钟菜单，而不是平铺所有按钮；
- 组件切换标的时释放旧实例；
- 没有真实信号时不存在 `B`、`S` 标记；
- 全屏与窄屏布局不溢出。

### 真实验收

- 当前价、昨收和涨幅与东财终端一致；
- 10:02 的分时点位于上午时段约四分之一处，右侧保持未来空白；
- 09:30、11:30、13:00、15:00 标签正确；
- 分时、1/5/15/30/60 分钟、日 K 均来自真实东财数据；
- 周、月、年与真实日 K 聚合结果一致；
- 正常模式主图至少 430px 高，全屏模式可用；
- 主题切换和窗口缩放后图表清晰；
- 仓库不包含 Token、原始行情转储或伪造信号。
