# 策略实验室实现计划（按用户需求重写）

> 状态：待确认
> 用户原话需求：
> 1. "跟首页一样 支持选择任何股票 然后选择时间段"
> 2. "下面要有一样的k线图"
> 3. "实时看到你在选择的时间段内的买卖点"
> 4. "旁边要有买卖 收益 统计"
> 5. "每天的模拟盘的交易完整的策略结果 要有存档 可以在这个实验室回放"
> 6. "未来用了充足的真实数据还可以继续训练模型"

---

## 1. 产品行为（按用户原话，不做"差不多"的替代）

用户在策略实验室页面操作：

1. **选股票**：顶部一个与首页"我的自选"完全一致的证券搜索框（输入代码或名称 → 真实证券搜索结果 → 选择任意股票，不限于已录数据）。**支持批量**：可连续添加多只股票（N 只）同时跑。
2. **选时间段**：起止日期选择（默认最近 30 个自然日）。
3. **选模型**：已批准的量化模型（默认 lgbm-minute-001）。
4. **看 K 线图**：下方展示与首页完全一致的**专业行情图**（分时/1m/5m/日K/周K/月K/年K 周期切换、MA/BOLL/VOL/MACD/KDJ/RSI 指标、十字光标联动、缩放），数据来自真实行情实时拉取（任何股票都能看，不需要先录制）。
5. **实时看到买卖点**：在所选时间段内，模型对该股票的分钟线逐根判断（BUY/SELL），买卖点以 B/S 标记**实时显示在 K 线图上**；盘中打开时按最新行情即时计算并随行情更新。
6. **旁侧统计**：净收益（金额与 %）、买卖次数、胜率、最大回撤、夏普、盈亏比、每笔交易明细（时间/方向/数量/价格/盈亏）。
7. **批量回放 + 视图切换**：选 N 只股票同时跑；每只一个结果，下方视图可切换（切换器与模拟盘持仓切换器一致），统计卡与 K 线随切换联动。
8. **每日存档（自动）**：模拟盘每次策略运行（5 秒自动循环、手动检查）**自动完整落库**到本地账本（决策、信号、风控、订单、成交全量，无需手动保存）。
9. **每日收益管理（策略实验室内）**：按日聚合展示——每天一条记录：日期、当日收益 %/金额、交易数、胜率；点击某天进入当天详情（K 线 + 当天买卖点 + 决策/成交明细）。**对比模式**：同一天可选"当天实际存档"或"用同一模型重新回放"，并列对比真实操作 vs 重算结果，复盘当日策略行为。
10. **实验报告**：手动点击"生成实验报告"→ 生成一份含统计的实验报告：全部标的的净收益/胜率/买卖次数/最大回撤/夏普/盈亏比汇总表 + 总体汇总 + 回放参数（标的、时间段、模型、阈值）；报告可在页面查看并可导出（文本/Markdown 复制）。
11. **训练模型**：当积累了充足真实数据后，可在此选择股票 + 时间段（或已录数据集）→ 训练新 LightGBM 模型 → 查看指标（AUC/净收益/交易数）与推荐阈值 → 注册为草稿 → 批准后接入实时环。
12. **DRAFT 模型可回放**：训练出的草稿模型可直接回放验证表现（不必先批准），结果显著标注"未批准模型，仅供参考，不代表可上线"。
13. **回放实验存档**：每次批量回放自动存为一条实验记录（参数：标的/时间段/模型/阈值/初始资金 + 结果摘要 + 时间戳）；页面有"历史实验"列表可回看/重新打开；实验报告基于存档生成。
14. **买卖点决策证据**：图上 B/S 点点击 → 显示该时点模型输出：上涨概率、特征快照、触发阈值、决策 ID。
15. **每日列表入金/出金金额**：每日收益列表显示当天充值/提现金额（从权益快照现金跳变推导）。
16. **批量回放取消**：运行中可中断；非交易日标注（所选区间含 N 个非交易日）；图上/报告标注"未模拟涨跌停与停牌"。

### 每日收益口径（设计说明）

- 数据来源：`paper_equity_snapshots`（每次盯市/成交/现金变更自动追加，全量保留）。
- 每日收益 = 当日最后一个快照 `total_equity` − 前一日最后一个快照 `total_equity`（相对前日收盘口径）。
- 交易日历：按上海时区归类日期；无快照的日期不展示。
- 说明标注：现金修改（外部入金/出金）会体现在当日收益中，界面提示"含外部资金调整"。

## 3. 技术方案

### 3.1 任意股票 + 时间段回放（后端，支持期初持仓起点）

- 新增 `POST /v1/research/replay`（改造现有）：请求 `{instruments: [{instrument_id, start_date, end_date, opening: {cash, positions: [{instrument_id, quantity, available_quantity, average_cost}]}}...], model_id, initial_cash}`——**支持多标的批量**，一次请求返回每只股票的回放结果数组。
- **回放引擎支持期初持仓**（`quant/replay.py` 扩展）：回放开始时建立期初持仓（数量/可用/成本），权益曲线从期初市值+现金起步；SELL 只卖可用数量（T+1 语义）；BUY 按模型信号加仓/补仓，受现金余额与仓位上限约束（与模拟盘执行口径一致）。
- 后端流程（每只标的）：
  1. `market_service.bars(instrument_id, period=1m, count=按时间段天数估算)` 从东财实时拉取该股票分钟线；
  2. 按日期过滤到所选时间段；
  3. 已批准模型逐根推理（复用 `quant/replay.py` 确定性引擎）；
  4. 返回：K 线 bars、买卖点、统计（净收益/胜率/买卖次数/最大回撤/夏普/盈亏比）、权益曲线、逐笔交易。
- 批量并发：多标的用 `asyncio.gather` 并发计算（每只独立）。
- 前端图表直接复用现有 `ProfessionalMarketChart`（首页同款）与 `MarketSignalMarker`（B/S 标记）。

### 3.1.0 充值（入金）与买入预算口径（重要）

- **充值是产品能力**：用户可随时修改"剩余现金"（现有 CashEditor），语义 = 向模拟账户入金/出金（`set_cash_balance` 已实现：调整 `initial_equity` 基线，不产生虚假策略盈亏）。买入没钱时先充值，再让模型操作。
- **模型买入预算 = 账户内所有钱（总资产）**：BUY 目标数量基于**当前总资产（现金 + 持仓市值，取最新权益）** × 单标的仓位上限，减去该标当前市值后取整到 100 股；**现金余额不足时拒单**（不超现金交易）。
- 回放（实验室）与模拟盘采用同一买入预算口径；回放过程本身不注入现金（充值只发生在模拟盘实际侧）。

### 3.1.1 日初状态自动存档（支撑同起点对比）

- 新增 `paper_daily_open` 表：`(account_id, trading_date, cash, positions_json, created_at)`。
- 自动机制：**每个交易日首次策略运行前**（`run_loop` 每次唤醒时检查当日是否已存档）自动快照账户持仓+现金写入；幂等（当天只存一次）。
- 用途：当天"实际 vs 重算"对比时，重算用**当天日初状态**（持仓+现金）作为起点，与实际从同一基线出发，收益可比。
- 历史日（存档机制上线前）无日初状态 → 界面明确标注"该日无日初存档，重算使用纯现金起点，收益不可与当天实际直接对比（仅对比信号/成交行为）"。

### 3.2 每日模拟盘存档、收益管理、回放与对比（后端）

- 存档自动写入：每次策略运行落库 `paper_strategy_runs`（决策/信号/风控/订单/成交 JSON 全量）+ `paper_equity_snapshots`（盯市/成交/现金变更自动追加）——**无需手动保存**（已实现）。
- 新增 `GET /v1/paper/accounts/{id}/strategy/daily`：返回每日聚合——日期、当日收益%（equity 快照日末差，**剔除现金调整日的跳变**）、当日成交笔数、当日决策数、是否有日初存档、当日是否有入金/出金。
- 新增 `GET /v1/paper/accounts/{id}/strategy/runs?date=YYYY-MM-DD`：返回当天全部决策记录（含信号、风控、订单、成交），按时间排序。
- 新增 `GET /v1/paper/accounts/{id}/strategy/daily-open?date=YYYY-MM-DD`：返回该日初状态（若有）。
- 前端"每日收益"区：日列表（收益%/金额/交易数/胜率）→ 点击某天进入详情；详情两种模式：
  - **当天实际**：展示存档（决策/成交列表 + 统计，含当天入金/出金记录与金额）。
  - **重新回放**：用同一模型对当天分钟线重算；**起点优先使用当天日初存档（持仓+现金）**；无存档时纯现金起点并显著标注不可比。**当天存在入金/出金时标注**："当日存在外部资金变动，重算未模拟充值"——实际侧收益按剔除现金调整口径后与重算对比（仅当日无资金变动时收益可直接对比）。

### 3.3 实验报告

- 前端"生成实验报告"：聚合本次批量回放全部结果 → 报告视图：
  - 参数头：标的列表、时间段、模型、阈值、初始资金；
  - 汇总表：每只股票 净收益% / 金额 / 胜率 / 买卖次数 / 最大回撤 / 夏普 / 盈亏比；
  - 总体：合计净收益、平均胜率、总交易数；
  - 导出：生成 Markdown 文本，可复制/下载（`navigator.clipboard` + Blob 下载 .md）。
- 后端无需新接口（报告由前端聚合现有回放结果生成）；可选后端 `POST /v1/research/report` 生成结构化 JSON（如未来需要分享）。本轮先做前端生成。

### 3.4 训练入口（后端已部分完成）

- `POST /v1/research/train`：`{dataset_ids 或 (instrument_id+日期范围), model_id, horizon, threshold}` → 拉数据 → 特征 → Purged/Embargo 切分 → LightGBM 训练 → AUC/净收益/交易数 → 推荐阈值 → 保存工件 → 注册 DRAFT。
- `POST /v1/research/datasets/record`：把"股票+时间段"存入研究库（训练数据来源）。
- 前端训练表单：选择股票+时间段（或已录数据集多选）→ 模型名 → 训练 → 结果 → 一键批准。

## 4. 任务分解

### Task 1: 后端回放接口改为任意标的 + 批量 + 期初持仓起点
- `quant/replay.py`：`replay_bars` 支持 `opening_positions`（数量/可用/成本，权益起点含期初市值；SELL 限可用，BUY 补仓受现金与仓位上限约束）。
- `paper_strategy_service.py`：模型 BUY 目标数量改为基于**当前总资产**（最新权益=现金+持仓市值）计算，单标的上限约束，现金不足拒单（提交时账本已拒）。
- `research_schemas.py`：`ReplayRequest` → `{instruments: [ReplayInstrumentInput], model_id, initial_cash}`；`ReplayInstrumentInput = {instrument_id, start_date, end_date, opening?}`；保留 `dataset_id` 兼容。
- `research_routes.py`：`replay` 返回 `list[ReplayView]`，多标的 `asyncio.gather` 并发；`market_service.bars` 拉分钟线 → 日期过滤 → `replay_bars`（带 opening）。

## 5. 不做（本轮边界）

- 不做真实行情事件推送（仍复用现有 5 秒轮询的行情接口）。
- 不做实盘。
- 训练不做深度学习（保持 LightGBM 基线）。
- 数据集录制保留为训练数据来源（后台能力），不作为回放的前置条件。
- 不做复权（除权除息处理单独排期；本轮在报告与图上标注"不复权"口径）。

## 6. 验收

- 在实验室输入任意 A 股/ETF 代码或名称（可批量多只）→ 选时间段 → K 线图（与首页交互一致）→ 图上出现模型 B/S 买卖点 → 旁侧统计齐全 → 切换器在 N 只标的间联动切换。
- 回放可带期初持仓起点（与模拟盘同基线）；批量回放有逐只进度反馈；数据范围与"仅已完成 bar"口径有标注。
- 盘中打开时买卖点随最新行情更新（重新运行即刷新）。
- 模拟盘每天自动存档日初状态；每日收益列表（剔除现金调整口径）可点击进入当天详情；同一天可对比"实际存档"与"同起点重新回放"（无日初存档时显著标注不可比）。
- 一键生成含统计、时间戳、模型版本与口径说明的实验报告并可导出。
- 训练入口可从"股票+时间段"数据训练出新模型并可批准。
