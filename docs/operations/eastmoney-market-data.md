# 东财掘金实时行情运维

## 安全边界

AstraQuant 仅使用东财掘金仿真环境的只读行情能力，不连接交易账户，也不发送委托。SDK
路径保存在本机状态库；Token 只写入 Windows 凭据管理器，不写入项目目录、日志、配置
文件或 Git。不要提交行情导出、终端截图、账号、密码或 Token。

## 首次连接

1. 启动“东财掘金量化终端”，选择“仿真”并登录测试账号。
2. 在终端的系统设置或密钥管理中取得行情 Token。不要把 Token 发到聊天、Issue 或日志。
3. 启动 AstraQuant：在仓库根目录执行 `./start.ps1`。
4. 打开“数据与连接”，确认 SDK Python 路径。当前推荐路径形如：
   `D:\AstraQuantData\Eastmoney\PythonSDK\Scripts\python.exe`。
5. 在密码框粘贴 Token，点击“保存并连接”。保存成功后输入框会立即清空。
6. 返回市场首页，检查上证指数、深证成指、创业板指、科创 50、沪深 300 和中证
   1000 六个固定槽位。

## 数据状态

- `LIVE`：刚收到真实事件，可按实时行情展示。
- `STALE`：最后事件超过延迟阈值；保留最后真实快照，但明确标记延迟。
- `CLOSED`：市场已收盘；数值只能作为最后真实快照，不能标记实时。
- `UNAVAILABLE`：SDK、Token 或终端尚不可用；所有缺失值显示“暂无真实数据”。
- `ERROR`：调用或协议失败；可检查终端后重新连接，程序不会用模拟值降级。

## 聚合探针

交易时段可运行：

```powershell
uv run python -m tools.eastmoney_probe --seconds 60
```

探针只请求六个核心指数，并只输出覆盖数、轮询次数、事件时间范围、延迟和错误计数。
它不会输出或落盘证券代码、价格、原始行情、Token 或账号。若确需保存验收结果，使用
`--output` 写到仓库外的本地目录；不要提交该 JSON。

退出码：`0` 收到有效事件；`2` 本机配置不可用；`3` 完成但没有当前事件；`4`
Provider 或协议失败。休市时没有推送不代表配置一定错误，需结合终端状态并在交易时段复验。

## 故障排查

- **终端未运行**：先启动终端并完成仿真登录，再点“重新连接”。
- **Token 无效**：在终端重新复制 Token，通过连接面板覆盖保存；不要写入 `.env`。
- **缺少 `gm`**：在终端 SDK 下载页选择受支持的 Python 版本安装 SDK，并确认该解释器可执行
  `import gm`。
- **盘后无推送**：确认 UI 显示 `CLOSED` 或“暂无真实数据”，在下一个 A 股交易时段运行探针。
- **连接延迟**：检查终端网络与登录状态；恢复后服务应自动取得新快照，不应制造补齐价格。
