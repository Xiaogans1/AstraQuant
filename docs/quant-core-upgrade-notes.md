# 量化核心优化 —— 交接笔记（2026-08-08）

> 用途：换会话继续讨论前的上下文梳理。包含用户质疑、已确认结论、已做改动、下一步路线。

## 一、用户的核心质疑（驱动本轮讨论）

1. **"全仓进出"不是真实量化**：回放结果里模型基本都是"全仓买入→全仓卖出"，很少做 T（日内 T+0 回补）。用户问：真实量化核心是这样操作的吗？**T+1 制度下每天也有仓位能操作**（底仓当日可卖、卖了可买回）。
2. **写死仓位是"拍脑袋"**：提出"每笔信号操作 1/3 仓"方案时，用户指出这是写死参数，不是模型在思考——**仓位应该由模型信号强度决定**。
3. **结果不理想**：当前回放经常高买低卖、很少做 T 高抛低吸。
4. **BS 不可解释**：用户要求能直观看到每次买卖的**策略原因**（图表统计、详细、易读）。

## 二、已确认的结论（文献/社区/学术）

- 主流实践**不是全仓进出**：
  - 仓位管理是策略核心（Kelly、风险平价、ATR 波动率目标仓位、信号强度定仓位）
  - A 股 T+1 下"底仓做T"是普遍玩法：当日先卖底仓→低位买回，本质是**日内均值回归**
  - 学术：A 股分钟级**短期反转效应**显著（Jegadeesh 1990 框架的日内版）；开闭市效应（9:30-10:00、14:30-15:00 波动最大，是做T窗口）；VWAP 基准
  - 开源参考：qlib（微软）、backtrader（Sizer 仓位管理）、vnpy、聚宽/掘金社区实践

## 三、当前引擎的缺陷清单

1. **信号→仓位是二值切换**：proba ≥ buy_threshold 全仓买、≤ sell_threshold 全卖，中间地带持有不动——无部分仓位
2. **模型只输出"涨跌概率"**：没有期望收益/目标仓位，无法自然映射仓位比例
3. **无止损/止盈规则层**：完全依赖信号，无 ATR 止损、日内亏损限额
4. **特征集偏"趋势"**：当前 10 个特征（return_1/3/5/10、volatility_5、vwap_deviation、volume_ratio、day_high_position、ma5_gap、ma20_gap）全是动量/趋势类，**缺少反转类特征**（做T 的核心信号源）
5. **做T 缺少专门建模**：引擎语义（T+1 冻结、日解冻）已支持，但信号模型不会产生"高抛低吸"模式

## 四、已完成的改进（本轮）

1. **BS 决策可解释**（commit 52ab90a 起）：
   - 回放引擎每笔交易记录**特征快照**（模型当时看到的 10 个特征）+ 决策原因（概率 vs 阈值）
   - 前端"**决策统计**"面板：买入画像 vs 卖出画像（每特征均值对比条形）→ 可诊断"高买低卖"根因（如买入画像动量/均线偏离为负 = 下跌接刀）
   - 选中 B/S 点显示**决策明细**：该时刻全部特征值条形图 + 中文语义标签
   - 特征中文元数据：FEATURE_META（StrategyLabPage.tsx）
2. **标记直接显示数量/盈亏**：B 显示份数、S 显示配对盈亏（红盈绿亏）
3. **做T 标记（黄色）**：同日 SELL→BUY 识别为做T，显示价差（代码在 ReplayResultView 的 isTrades）
4. **持仓成本线**（橙色虚线）：
   - 买入 B = 红、卖出 S = 蓝（用户确认的国内惯例）、做T = 黄、盈利红/亏损绿、成本线黄
   - 注意：用户最后确认"选中芯片"用 accent 青绿；买卖点 B 红 S 蓝

## 五、量化核心升级路线（下一步，待用户确认优先级）

1. **模型输出升级**：二分类概率 → **目标仓位回归/期望收益**（信号强度自然映射仓位，不写死）
2. **加反转特征**：分钟级短期反转因子（做T 信号源），配合 T+1 可用仓位约束
3. **止损/止盈规则层**：ATR 止损、日内亏损限额（信号之外的风控）
4. **分层回测**：单独统计"趋势段收益 vs 做T 段收益"，验证做T 能力
5. 可选：分钟级数据已有（5000 根/标的），可引入盘口/资金流特征（需数据源支持）
